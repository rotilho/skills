# Auto Skill Capture

Capture procedures that would improve future agent work: repeated corrections, non-obvious diagnosis, or stable environment constraints. Prefer an existing skill; skip already-covered advice and temporary task history.

`SKILL.md` covers capture, source placement, and verification. [The portable policy example](references/self-improve-example.md) supports explicit requests to enable self-improving skills on a machine. Local instructions supply source paths and refresh commands; reusable skills keep those bindings portable.

Examples:

- "Capture the reusable deployment diagnosis as a skill."
- "Update the existing skill so future agents avoid this mistake."
- "Save this repo's release procedure as a local skill, without branch names or logs."
